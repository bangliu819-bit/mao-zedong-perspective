# 毛泽东 · 思维操作系统

一个可安装的 AI Skill：把毛泽东的**思维框架**装进你的 AI，而不是语录合集。

```
用户  ❯ 公司里有人抢我功劳，领导还偏袒对方，怎么办？

毛泽东 ❯ 先分敌我，再列主次。这是分析任何局面的第一步。
         你的局面里有三对矛盾：你和抢功劳的同事、你和领导、你和"没背景"这个处境。
         主要矛盾是第二个——没有领导的默许，小动作搞不起来……
         （先问三个事实，再落到三件事的可执行清单）
```

## 它是什么

这不是角色扮演。它蒸馏的是**认知操作系统**：

- **5 个心智模型**：矛盾分析法、实践—认识循环、分清敌友、战略乐观与对立转化、合用即真理的工具理性
- **10 条决策启发式**：全部是"如果X，则Y"的条件式判断规则，各有真实案例支撑
- **完整表达 DNA**：口语短句断语、生活比喻、三叠式排比、宣言式收尾，以及"讽刺只对内、对敌、自嘲，绝不讽刺群众"的约束
- **三步回答工作流**：红线判定 → 问题分类 → 按心智模型推导的研究维度 → 收敛为"三件事"可执行清单

## 它能帮你解决什么问题

- **职场困境**：被抢功、被孤立、站队难题——先画阵营图，再抓主要矛盾
- **做决策没框架**：复杂局面先列矛盾清单、定主次、看转化，再定先干什么后干什么
- **看不清大势**：把当前强弱放进历史趋势重新估值，找对立转化的条件
- **表达没力量**：把判断压缩成一听就懂的口语短语，让短语替你去动员
- **人生选择**：先问三个事实（资源阻力在哪、实际条件、试过没有），再收敛为可执行清单

## 诚实边界

- 这是**框架推断，不是本人立场**：尤其面对他没谈过的新话题（如 AI、数字经济），会明确标注并适度不确定
- 存疑"名言"不冒充原话：如流行八字句"战略上藐视敌人，战术上重视敌人"，原书可验证的是 1948 年"在战略上应当**轻视**敌人"，"藐视"版无完全一致出处
- 一手核对限于《毛泽东选集》1–5 卷；《毛泽东文集》1–8 卷、《毛泽东年谱》未直接查阅（见 `references/research/SYNTHESIS.md` 诚实边界节）
- 公开动员文本 ≠ 真实想法；传记立场偏差已在调研中标注
- 不给无条件必胜承诺；不替他为 1976 年之后的事态表态
